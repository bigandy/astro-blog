Yesterday I was coding an app with solid and I wanted to use the new `selectedcontent` html element that is available inside `<select>` elements. Combined with some CSS it enables you to be able to style dropdowns in any way you want. `selectedcontent` specifically allows you to have custom html within the options and be able to style the selected option:

<SelectExample isModern={true} />

```javascript
export const LanguageSelector = () => {
    return (
        <select id="languageSelection">
            <button>
                <selectedcontent />
            </button>
            <option value="en">
                <span class="icon" aria-hidden="true">
                    🇬🇧
                </span>
                English
            </option>
            {...other options}
        </select>
    );
};```

```css title="index.css"
::picker(select),
select {
    appearance: base-select;
}

selectedcontent {
    display: flex;
    flex-direction: row-reverse;
    gap: 1rem;
}
```

### The Error

```bash
Property 'selectedcontent' does not exist on type 'JSX.IntrinsicElements'.ts(2339)
```

### How to fix the error

1. create a global.d.ts file.this will go at the root of the project or the root of where your tsconfig.json file is pointing at e.g.the src folder.

<details open>
    <summary>Solid</summary>

```javascript
// global.d.ts for Solid

import "solid-js";

declare module "solid-js" {
    namespace JSX {
        interface IntrinsicElements {
            /**
            * The <selectedcontent> element displays a clone of the currently
            * selected <option>'s content inside a customizable <select>.
            */
            selectedcontent: object;
        }
    }
}
```
</details>

<details>
    <summary>React</summary>

```javascript
// global.d.ts for React
import "react";

declare module "react" {
    namespace JSX {
        interface IntrinsicElements {

}
```
</details>
