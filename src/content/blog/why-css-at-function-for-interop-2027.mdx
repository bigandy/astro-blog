## What is the CSS @function?
Like functions in JavaScript the CSS @function allows the developer to write a custom expression contianing variables, variables, @media and @container queries. You can then use this function in any place where you would normally use a value.

```css
@function --spacing(--multiplier <number>, --unit: 16px <length>) {
    result: calc(var(--multiplier) * var(--unit));
}

header {
    margin-block: --spacing(3); /* outputs: 48px (3 * 16px)
    /* or with a different unit */
    margin-inline: --spacing(3, 1rem); /* outputs: 3rem */
}

```

## What is Interop?
Every year the main browser engines (Chrome, Safari, Firefox, and Edge) put up a call for the submissions. It is called Interop. It is an effort to improve the web in areas that developers want. ## What is the new @function custom at-rule?

Have you ever wanted a piece of code that you can call over and over without worrying that you might get the details wrong between uses of it?

You have a design system and want to apply a variant of a spacing token. Say you want a spacing of 3 tokens.

To do this in the past you would have had to multiply the spacing token by 3:

```css
.component {
    padding: calc(var(--spacing) * 3);
}
```

```css
/* Define the function once */
@function --spacing(--multiplier) {
    result: calc(var(--spacing) * var(--multiplier));
}
/* use the function multiple times */
.component {
    padding: --spacing(3);
    margin-block-end: --spacing(1);
}
```

### Default value of function parameter
```css
@function --spacing(--multiplier: 1) {
    result: calc(var(--spacing) * var(--multiplier));
}

/* will allow you to use it like so without a value */
.component {
    padding: --spacing();
    /* is the same as */
    padding: --spacing(1);
}
```

### Define the type of each function parameter
```css
@function --spacing(--multiplier <number>: 1) {
    result: calc(var(--spacing) * var(--multiplier));
}
/* works ✅ */
.component {
    padding: --spacing(3);
}

/* will not work ❌ */
.component {
    padding: --spacing(3px);
}
```

### Specify the type that is returned by the function
```css
@function --spacing(--multiplier <number>: 1) returns <number> {
    result: calc(var(--spacing) * var(--multiplier));
}
```

## Ideas on naming conventions
I think that it is easy to get confused between all of the `<dashed-indent>`s that are now available in CSS. Custom variables, @keyframes, anchor-name, animation-name, container-names, view-transition-names... and now @function.

In my own code I have begun using the `--f-` prefix so that it is obvious that I am intending to use a @function. For example:

```css
@function --f-spacing(--multiplier <number>: 1) {
    result: calc(var(--spacing) * var(--multiplier));
}
.component {
    padding: --f-spacing(3);
}
```
